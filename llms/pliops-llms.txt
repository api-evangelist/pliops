# Pliops

> Pliops is an Israeli data-acceleration semiconductor company (founded 2017, Ramat Gan) that builds
> the Extreme Data Processor (XDP), a low-profile PCIe accelerator card that offloads storage and
> key-value data-path work from server CPUs. Its software surface is a host-side library, not a web
> API: XDP-AccelKV / XDP-Rocks expose a RocksDB-API-compatible key-value engine used as a drop-in
> under MySQL/MyRocks, Redis, KVRocks, TiDB, Kafka and Spark, and XDP LightningAI extends the same
> acceleration to GenAI KV-cache offload for vLLM-based inference. Pliops was acquired by Astera Labs
> in February 2026.

## What an agent can and cannot do here

Pliops operates NO public network API. There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, JSON Schema, Postman collection, MCP server or A2A agent card published
anywhere, and no first-party SDK in npm, PyPI, RubyGems, crates.io or Maven Central. Access to the
XDP libraries runs through a sales/evaluation conversation (demo@pliops.com). An agent cannot call,
authenticate against, or integrate with Pliops programmatically over the network.

## Products (marketing surface, no machine-readable contract)

- XDP — Extreme Data Processor: PCIe data accelerator card
- XDP-AccelKV: accelerated key-value data service for RocksDB / WiredTiger-class storage engines
- XDP-Rocks: RocksDB-API-compatible drop-in key-value engine
- XDP LightningAI: GenAI KV-cache offload and acceleration for LLM inference

## Corporate

- Acquired by Astera Labs, February 2026 (~$70M; assets, IP and roughly half of staff moved into a
  new Astera Labs R&D center in Israel).
- Total funding prior to acquisition: approximately $205M across 5 rounds.
